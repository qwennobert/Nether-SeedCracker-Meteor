===============================================================================
  NETHER SEED CRACKER - Guide
  Meteor Client addon for Minecraft 1.21.10 and 1.21.11
===============================================================================

Nether Seed Cracker reads the bedrock in the Nether and finds the world seed
from it. You only enable the module and go to the Nether, everything else
happens on its own.

Meant for testing on your own server or in singleplayer. On other people's
servers this is cheating and will get you banned.


-------------------------------------------------------------------------------
 1. WHAT YOU NEED
-------------------------------------------------------------------------------

Put all of these into the "mods" folder of your Minecraft instance:

  [x] Fabric Loader 0.18.2 or newer
  [x] Meteor Client for your Minecraft version (1.21.10 or 1.21.11)
  [x] nether-seedcracker-<version>+mc1.21.11.jar   (for Minecraft 1.21.11)
      or
      nether-seedcracker-<version>+mc1.21.10.jar   (for Minecraft 1.21.10)

  Optional:
  [ ] SeedMapper   -> can receive the cracked seed
  [ ] Seed Miner   -> receives the cracked seed as manual seed

Java 21 or newer, like Minecraft itself.


-------------------------------------------------------------------------------
 2. WHERE DO I GET THE JAR?
-------------------------------------------------------------------------------

  a) GitHub: repository -> "Releases" -> top release ("Latest")
     Every release contains one jar per Minecraft version. Take the one that
     ends with your version, e.g. "+mc1.21.11".
     Delete the old jar from the mods folder before you add a new one.

  b) Build it yourself:
       ./gradlew build                 (Minecraft 1.21.11)
       ./gradlew build -Pmc=1.21.10    (Minecraft 1.21.10)
     (Windows: gradlew.bat instead of ./gradlew)
     The jar is then in build/libs/


-------------------------------------------------------------------------------
 3. QUICK START (4 STEPS)
-------------------------------------------------------------------------------

  1. Open the Meteor GUI: RIGHT SHIFT.
     Category "Nether Cracker" -> module "nether-seed-cracker".
     Left-click to enable it.

  2. Go into the Nether (any place, you don't have to go down to the
     bedrock, the chunks only have to be loaded).

  3. The module starts cracking on its own. In chat you see:
         Cracking with 64 floor and 64 roof blocks on 4 threads ...
     Progress and time left are on the module page and in the HUD.

  4. After about 1 to 3 minutes:
         World seed: 7368651628869333169 (matches the hashed seed of the server)
     Click the number to copy it.

  TIP: Add the HUD element: Meteor GUI -> HUD -> "nether-cracker".


-------------------------------------------------------------------------------
 4. HOW DOES IT WORK?
-------------------------------------------------------------------------------

Since 1.18 the bedrock at the bottom (y 1-4) and the top (y 123-126) of the
Nether is placed randomly, and that random comes from the world seed. Each
bedrock block (or missing bedrock block) tells something about the seed.

  - The addon reads these layers in the loaded chunks around you.
  - It picks the 64 most telling blocks of the floor and of the roof.
  - It tries all 2^48 possible seeds of one surface on background threads,
    but most are ruled out after a few blocks. Hits are checked against the
    other surface. That gives the "structure seed" (lower 48 bits of the
    world seed).
  - The missing upper 16 bits come from the "hashed seed": the server sends a
    hash of the world seed to every player when joining. The addon tries all
    65536 possibilities and takes the one with the same hash. That is the
    exact world seed.

Two different structure seeds can make exactly the same bedrock. The hashed
seed tells which one is right.


-------------------------------------------------------------------------------
 5. SETTINGS
-------------------------------------------------------------------------------

General
  auto-start          Start on its own once there is enough data.   (on)
  scan-radius         Chunks around you that are read.               (2)
  max-blocks          Blocks per surface used for cracking.          (64)

Cracker
  threads             CPU threads. More = faster, but the game may
                      lag a little.                    (half of your threads)
  generation          Vanilla (normal), or PaperOld if the Nether was
                      generated by PaperMC before 1.19.2 build 213
                      (the bedrock then looks like pillars).
  use-hashed-seed     Use the server's hashed seed for the exact
                      world seed.                                    (on)
  stop-when-found     Stop as soon as the hashed seed matches.       (on)

Output
  save-to-file        Write results to
                      .minecraft/meteor-client/nether-seedcracker/seeds.txt
  send-to-seedmapper  Save the seed for this server in SeedMapper
                      (/sm:config SavedSeeds add <seed>).            (off)
  send-to-seed-miner  Give the seed to the Seed Miner addon
                      (.seedminer seed <seed>).                       (on)

Render
  render              Show the bedrock blocks that are used.         (off)


-------------------------------------------------------------------------------
 6. COMMANDS
-------------------------------------------------------------------------------

  .nsc            status
  .nsc start      start now (also with little data)
  .nsc stop       stop, the collected data is kept
  .nsc reset      forget data and result, e.g. to crack again
  .nsc seeds      list all found structure seeds
  .nsc export     save the collected bedrock to a file
                  (format "x y z Bedrock/Other" of the Nether Bedrock Cracker)


-------------------------------------------------------------------------------
 7. TROUBLESHOOTING
-------------------------------------------------------------------------------

"Go to the Nether"
  The module only collects in the Nether.

"No seed matches the bedrock"
  - The Nether around you was generated before 1.18 (old bedrock pattern).
    Go somewhere you have never been before and use .nsc reset.
  - The server is (or was) an old PaperMC version: set generation = PaperOld
    and use .nsc reset.

"No structure seed matches the hashed seed of the server"
  The server sends a fake hashed seed. The structure seeds and the possible
  world seeds are listed anyway. The structure seed is enough for structures
  and ores.

The game lags while cracking
  Lower "threads".

Use it with Seed Miner
  Keep send-to-seed-miner on. Seed Miner then uses the cracked seed as its
  manual seed, nothing else to do.
