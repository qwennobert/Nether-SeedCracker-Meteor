# Nether Seed Cracker – Meteor Client addon (Minecraft 1.21.10 / 1.21.11)

Nether Seed Cracker finds the world seed from the bedrock in the Nether, fully automatically. Enable the module, go to
the Nether, and a minute or two later the seed is in chat.

It is a Java port of [19MisterX98's Nether Bedrock Cracker](https://github.com/19MisterX98/Nether_Bedrock_Cracker),
built into Meteor: the bedrock is read from the loaded chunks, no typing in coordinates. Afterwards the hashed seed the
server sends on join turns the result into the exact 64 bit world seed.

A detailed step-by-step guide is in [GUIDE.txt](GUIDE.txt).

> Meant for testing on your own (self-hosted) server or in singleplayer. On other people's servers this is cheating and
> will get you banned.

## How it works

1. **Collect**: Since 1.18 the bedrock at y 1–4 (floor) and y 123–126 (roof) of the Nether is random, and the random
   comes from the world seed. The module reads these layers from the loaded chunks around you. A single chunk has
   plenty of data; the 64 most informative blocks of each surface are used (bedrock at y 4 and 123, other blocks at
   y 1 and 126 are rare and say the most).
2. **Crack**: On background threads the 48 bit seed of one surface is searched: the upper 36 bits one by one, the lower
   12 bits in a tree, where every block can already rule out seeds with unknown lower bits. Every hit is checked against
   the other surface and reversed to the **structure seed** (lower 48 bits of the world seed).
3. **World seed**: The upper 16 bits don't affect the Nether. The server sends the client a hash of the world seed
   (SHA-256, for biome blending), so the addon tries all 65536 upper bits and takes the one with the right hash. This
   also works for seeds the admin typed in. If the server hides the hashed seed, the addon lists the world seeds a random
   seed (`new Random().nextLong()`) or a text seed could be.
4. **Output**: The seed appears in chat (click to copy), is saved to
   `.minecraft/meteor-client/nether-seedcracker/seeds.txt`, and can be handed to SeedMapper and the
   [Seed Miner](https://github.com/qwennobert/Meteor-seedcracker) addon.

The full search takes about 3 minutes on 4 CPU threads. With the hashed seed it stops at the match, on average after
half of that. Tested against real 1.21.10 and 1.21.11 servers (random seed and text seed): every bedrock block matched
and the exact seed was found.

## Installation

Put these into your `mods` folder:

| Mod | Required | Notes |
|---|---|---|
| [Fabric Loader](https://fabricmc.net/use/) ≥ 0.18.2 | yes | |
| [Meteor Client](https://meteorclient.com/) 1.21.10 or 1.21.11 | yes | same version as Minecraft |
| Nether Seed Cracker (`nether-seedcracker-<version>+mc1.21.11.jar` or `+mc1.21.10`) | yes | this addon, from the latest [release](../../releases/latest), pick the jar for your Minecraft version |
| [SeedMapper](https://modrinth.com/mod/seedmapper) | no | can receive the seed |
| [Seed Miner](https://github.com/qwennobert/Meteor-seedcracker) | no | receives the seed as manual seed |

Java 21 or newer is required (the same as Minecraft 1.21.10/1.21.11).

## Usage

1. Open the Meteor GUI (Right Shift) → category **Nether Cracker** → module **nether-seed-cracker** and enable it.
2. Go to the Nether. As soon as a chunk is loaded, cracking starts on its own.
3. Wait for the chat message `World seed: ...` (click it to copy).
4. Optional: add the **nether-cracker** element in Meteor's HUD editor (status, progress, time left, seed).

The module page shows the status and the collected data, plus the buttons *Start*, *Stop*, *Reset* and *Copy seed*.
The result stays until you use *Reset* or join another server.

### Settings

| Group | Setting | Description |
|---|---|---|
| General | `auto-start` | Start cracking on its own once enough bedrock is collected (default on) |
| | `scan-radius` | Loaded chunks within this many chunks around you are read (default 2) |
| | `max-blocks` | Blocks per surface (floor and roof) the cracker uses, the most informative ones are picked (default 64) |
| Cracker | `threads` | CPU threads for cracking (default: half of your threads) |
| | `generation` | `Vanilla`, or `PaperOld` for nethers generated by PaperMC before 1.19.2 build 213 (bedrock looks like pillars) |
| | `use-hashed-seed` | Use the hashed seed from the server to get the exact world seed (default on) |
| | `stop-when-found` | Stop as soon as a seed matches the hashed seed (default on) |
| Output | `save-to-file` | Append results to `meteor-client/nether-seedcracker/seeds.txt` |
| | `send-to-seedmapper` | Save the seed for this server in SeedMapper (`/sm:config SavedSeeds add <seed>`), if installed (default off) |
| | `send-to-seed-miner` | Set the seed as manual seed of Seed Miner (`.seedminer seed <seed>`), if installed (default on) |
| Render | `render`, `shape-mode`, colors | Highlight the bedrock blocks that are used |

### Command

```
.nsc                 status (also .nethercracker)
.nsc start           start cracking now (also with little data)
.nsc stop            stop cracking, the collected bedrock is kept
.nsc reset           forget the collected bedrock and the result
.nsc seeds           list all structure seeds that were found
.nsc export          save the collected bedrock as x y z Bedrock|Other (format of the Nether Bedrock Cracker)
```

## Limitations

- Only nethers generated in 1.18 or newer. Older chunks have the old bedrock pattern; use the fungus cracker of
  [SeedcrackerX](https://github.com/19MisterX98/SeedcrackerX) there.
- The overworld bedrock uses a different random (Xoroshiro) and is not supported.
- Two structure seeds can generate exactly the same bedrock. With the hashed seed only the right one is shown,
  without it you get both.
- If the server sends a fake hashed seed (some anti-seedcracker plugins), only the candidates are listed. Seeds typed
  in by the admin (not random, not text) can then not be completed, the structure seed is still right.
- Paper's anti-xray doesn't matter: it never hides or fakes bedrock.

## Building

```bash
./gradlew build                # Minecraft 1.21.11
./gradlew build -Pmc=1.21.10   # Minecraft 1.21.10
```

The jar ends up in `build/libs/`. The Minecraft, yarn and Meteor versions are in `versions/<mc>.properties`.
`./gradlew runClient` starts a dev client with Meteor.

`./gradlew test` checks the cracker (against Minecraft's own random classes and the example data of the Nether Bedrock
Cracker). The full 2^48 search is a benchmark that only runs with `./gradlew test -Dnsc.fullSearch=true`.
